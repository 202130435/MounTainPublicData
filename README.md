# 꽃때 — 식물계절 관측자료 기반 축제 기간 설계 도구

첨부된 최신 `웹 테스트.html`의 세 화면·레이아웃·테마를 바탕으로 실제 자료를 연결한 C파트 작업입니다. 공개 서비스가 아닌 팀 내부 분석·시연용입니다.

## 사용

생성된 `꽃때_실제자료_내부시연.html`을 일반 Chrome에서 엽니다. 외부 스크립트·API·폰트·지도 타일 요청 없이 데이터를 내장하므로 Python 서버나 인터넷이 필요하지 않습니다. 기업/학교 관리형 Chrome이 `file://`를 차단하면 허용된 브라우저를 사용하거나 아래 로컬 HTTP 방식으로 실행합니다. 이 작업의 관리형 Chrome에서는 파일 접근이 차단되어 직접 파일 탐색은 검증하지 못했고, 동일 HTML의 오프라인 문서 실행과 로컬 HTTP 실행을 검증했습니다.

```
python -m http.server 8765 --bind 127.0.0.1 --directory /path/to/outputs
```

지역 경계와 관측지 표식 선택을 입력과 연동했습니다. 전국 지역 목록의 완전성은 ver20261001 가공 파일에 대한 포함 검사이며 공식 최신성 보증이 아닙니다. 실제 관측지로 표시하는 것은 정제본의 전시원 10곳뿐입니다.

## 재생성

기존 체크아웃을 사용합니다. 별도 Git worktree는 필요하지 않습니다. 첨부 자료는 저장소 밖에 안전하게 해제합니다. 실제 데이터는 재배포 조건이 확인되지 않았으므로 이 저장소에 포함하지 않습니다.

```
python -m venv .venv
.venv/bin/python -m pip install -r requirements-build.txt
.venv/bin/python tools/build.py /path/to/data /path/to/HangJeongDong_ver20261001.geojson /path/to/outputs
```

행정 경계 입력: https://raw.githubusercontent.com/vuski/admdongkor/master/ver20261001/HangJeongDong_ver20261001.geojson

검증에 사용한 원본 SHA-256: `843ece3a0b3429742cd4a1b699cc13987a88b5e5401f382e7fdaaa194ea5e605`

이 URL은 master 브랜치로 변경될 수 있으므로 재생성 시 원본 해시를 확인합니다. 저장된 해시와 다르면 기존과 같은 지역 구성이라고 간주하지 말고 다시 조사합니다. 데이터 이용 조건은 `docs/ADMIN-LICENSE-DATA.txt`를 확인합니다. SGIS 및 vuski 출처 표기는 HTML에 포함되어 있습니다.

## 검증

검증 도구는 Python Playwright와 시스템 `/usr/bin/chromium`을 사용합니다. 테스트용 환경에만 필요하며 최종 HTML 사용자에게는 필요하지 않습니다.

```
python -m pip install -r requirements-test.txt
python tools/verify.py /path/to/data /path/to/outputs
```

독립적인 pandas 재계산, 모든 지점·지원 조합의 수치 범위, 선택 유지, 테마, 자료 부족, 잘못된 날짜, 윤년, 대안 적용, CSV 저장, 모바일 레이아웃, 오프라인 실행을 검사합니다. 합성 자료는 경계조건 단위검사에만 사용하며 화면 결과에는 넣지 않습니다.

## 계산과 한계

- 분석: A 임시 정제본의 수목원·종·단계·연도 대표값. 표본 표준편차와 유효 연수를 함께 표시합니다. 이상치 의심 기록은 기본 제외하고 선택적으로 포함할 수 있습니다.
- 일정: 나무 단위 시작~낙화 기록을 같은 나무·같은 해끼리 짝지어 연도 대표 구간을 만듭니다. 세부 기준은 HTML 및 `docs/C파트_검토와_협업.md`에 있습니다.
- 8년 기준은 A 메모와 자료 분포에 따른 임시 기준입니다. 통계적 충분성을 보증하지 않습니다.
- 관람 구간의 대리값으로 ‘개화시작~낙화90~100% 기록상 구간’을 사용합니다. 관광객 관람 적기나 개화 지속시간의 정밀 측정값이라고 단정하지 않습니다.
- 단풍 구간 정의, 기관 판정 원문, 미래 예측 모델은 미확정입니다. 해당 계산은 비활성 상태입니다.
- 과거 자료에 최적화한 대안 일정을 미래 성능이나 순차 검증 결과로 표현하지 않습니다.
